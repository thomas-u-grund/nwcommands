# The nwrem manual

The manual is the reference for `nwrem`. It covers the model (the ordinal and the waiting-time likelihood, risk sets, the posterior mode), installation, data preparation, every effect and option, stored results, worked examples with real output, the comparison with relevent, the limits and technical notes.

**[Download the manual (PDF, 53 pages)](../nwrem_manual.pdf)**

The manual describes `nwrem` 1.4 (the current release is 1.4.0). Cite it as:

> Grund, T. U. (2026). *nwrem: Relational event models in Stata. Manual.* [https://nwcommands.org/nwrem/nwrem_manual.pdf](https://nwcommands.org/nwrem/nwrem_manual.pdf)

together with the exact package version printed by `nwrem version`.
