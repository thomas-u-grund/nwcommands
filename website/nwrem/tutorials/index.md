# nwrem tutorials
{: .no_toc }

Worked tutorials for nwrem, each with real Stata output. Install the package first (see [Install](../install/)).

- [Tutorial 1: A first relational event model](/nwrem/tutorial-1-first-rem/): Fit a first relational event model with nwrem to a log of phone calls: declare the event sequence, fit degree and inertia effects, and read the coefficient table.
- [Tutorial 2: Effects and interpretation](/nwrem/tutorial-2-effects/): Add actor covariates, a pair covariate and recency effects to a relational event model with nwrem, and read what each one says.
- [Tutorial 3: Comparing specifications](/nwrem/tutorial-3-comparing/): Compare relational event models fitted with nwrem by log likelihood, AIC, BIC and likelihood-ratio tests, check that the estimates are stable, and see what the command refuses.
