# How to cite

**nwrem.** Cite the package by its repository and report the version that produced your results, as printed by
`nwrem version` (for example "nwrem 1.0.10"). The package has no DOI:

> Grund, T. U. (2026). *nwrem: a Stata package for relational event models (version 1.0.10).* GitHub. [https://github.com/thomas-u-grund/nwrem](https://github.com/thomas-u-grund/nwrem)

Please also cite the core package, nwcommands.

**The model and relevent.** `nwrem` implements the model of Butts and was checked against relevent, so please also cite them:

- Butts, C. T. (2008). A relational event framework for social action. *Sociological Methodology* 38(1), 155-200. [doi:10.1111/j.1467-9531.2008.00203.x](https://doi.org/10.1111/j.1467-9531.2008.00203.x)
- Butts, C. T. *relevent: Relational Event Models.* R package, [CRAN](https://cran.r-project.org/package=relevent) (compared with version 1.2-1).
