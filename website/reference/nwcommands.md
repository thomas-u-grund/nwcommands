# `nwcommands`

Start page of the nwcommands help in Stata: type `help nwcommands`. It lists the help topics
[`nwintro`](nwintro), [`nwtopical`](nwtopical), [`nwalphabetical`](nwalphabetical),
[`nwstart`](nwstart), [`nwprogramming`](nwprogramming), [`nwinstall`](nwinstall) and
[`nwinternals`](nwinternals), and says which version is installed.

On this website, the [command reference](./) is the same material, grouped by task. The statistical
model packages have their own sections: [nwsaom](../nwsaom/), [nwergm](../nwergm/),
[nwdynam](../nwdynam/) and [nwrem](../nwrem/).
