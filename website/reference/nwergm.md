# `nwergm`

`nwergm` (exponential-family random graph models (ERGM)) has moved to its own package, licensed under GPL-3.

```stata
net install nwergm, from(https://raw.githubusercontent.com/<account>/nwergm/main/)
```

The package requires the core `nwcommands`. Repository: https://github.com/<account>/nwergm
