# `nwdendrogram`

Plot a wheel dendrogram

## Syntax

```stata
nwdendrogram
[clname] 
[, options twoway_options]
```

## Description

Displays results from hierarchical clustering (see [nwhierarchy](nwhierarchy) or `cluster`) as wheel dendrogram.
