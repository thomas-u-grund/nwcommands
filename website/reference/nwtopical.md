# `nwtopical`

Commands grouped by task: concepts, import and export, generators, information, manipulation, analysis,
utilities, visualization and programming. The [command reference](./) on this website has the same
grouping. In Stata: `help nwtopical`. For an alphabetical list, see [`nwalphabetical`](nwalphabetical).
