# `nwintro`

Help topic with an introduction to network data in Stata (nodes, ties, the adjacency matrix),
the limits on network size, how network commands relate to ordinary Stata commands, how to give
feedback, how to get involved and how to cite the package. In Stata: `help nwintro`.

For a hands-on start, see the [tutorials](../tutorials/), beginning with
[Core Concepts](../tutorials/02-core-concepts/), and [`nwstart`](nwstart). To cite the
packages, see [Citing and licenses](../citing/).
