# `nwstart`

Help topic for first steps: declaring data as a network ([`nwset`](nwset)), getting network data into
Stata, plotting and animating networks, simulating networks, handling and manipulating them and
analyzing them. In Stata: `help nwstart`.

The [tutorials](../tutorials/) cover the same ground with worked output. Related commands:
[`nwwebuse`](nwwebuse), [`nwfromedge`](nwfromedge), [`nwplot`](nwplot), [`nwrandom`](nwrandom),
[`nwsummarize`](nwsummarize).
