# The nwalaam manual

The manual is the reference for `nwalaam`. It is archived at Zenodo under the DOI of all versions, so the link always
leads to the latest manual.

**[Manual](https://doi.org/10.5281/zenodo.24397901)**

Cite it as:

> Grund, T. U. (2026). *nwalaam: Autologistic actor attribute models in Stata. Manual.* Zenodo. [https://doi.org/10.5281/zenodo.24397901](https://doi.org/10.5281/zenodo.24397901)

together with the exact package version printed by `nwalaam version`.
