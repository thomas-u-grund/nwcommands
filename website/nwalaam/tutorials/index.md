# nwalaam tutorials
{: .no_toc }

Worked tutorials for nwalaam, each with real Stata output. Install the package first (see [Install](../install/)).

- [Tutorial 1: A first ALAAM on the karate club](/nwalaam/tutorial-1-first-alaam/): Fit a first autologistic actor attribute model with nwalaam to the karate club, compare the estimators with the exact maximum likelihood estimate, and check the fit.
- [Tutorial 2: Smoking in the Glasgow friendship network](/nwalaam/tutorial-2-glasgow/): Fit contagion and covariate effects for smoking in a school friendship network, check the fit, simulate, and see what the contagion term does not say.
