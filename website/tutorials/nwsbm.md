You need the core and the package [nwsbm](/nwsbm/) ([how to install it](/nwsbm/install/)).

- [Tutorial 1: Blocks in the karate club](/nwsbm/tutorial-1-first-sbm/): choosing the number of blocks, and what the blocks are.
- [Tutorial 2: Covariates, the exact ICL and two-mode blocks](/nwsbm/tutorial-2-covariates-greedy/): covariates with standard errors, the greedy search, the degree-corrected two-mode model, block variances.
