# Dynamic network actor models with nwdynam
{: .no_toc }

**The question:** Who sends the next time-stamped event, and to whom?

You need the core and the package [nwdynam](/nwdynam/) ([how to install it](/nwdynam/install/)).

- [Tutorial 1: A first DyNAM](/nwdynam/tutorial-1-first-dynam/): event data, the rate and the choice sub-model, reading the table.
- [Tutorial 2: Effects and interpretation](/nwdynam/tutorial-2-effects/): covariates, closure, windows, comparing models.
- [Tutorial 3: Limits and diagnostics](/nwdynam/tutorial-3-limits/): what a small event log can and cannot tell you.
