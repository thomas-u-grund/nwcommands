# Relational event models with nwrem
{: .no_toc }

**The question:** What drives the order of time-stamped events between actors?

You need the core and the package [nwrem](/nwrem/) ([how to install it](/nwrem/install/)).

- [Tutorial 1: A first relational event model](/nwrem/tutorial-1-first-rem/): the event sequence, degree and inertia effects, reading the table.
- [Tutorial 2: Effects and interpretation](/nwrem/tutorial-2-effects/): actor and pair covariates, recency, side-by-side comparison.
- [Tutorial 3: Comparing specifications](/nwrem/tutorial-3-comparing/): AIC, BIC and likelihood-ratio tests, stability, limits.
