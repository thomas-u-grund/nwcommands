# Latent space models with nwlsm
{: .no_toc }

**The question:** Where would each actor sit on a map in which close actors are more likely to be tied?

You need the core and the package [nwlsm](/nwlsm/) ([how to install it](/nwlsm/install/)).

- [Tutorial 1: A latent space for the karate club](/nwlsm/tutorial-1-first-lsm/): fit, diagnostics, positions and goodness of fit.
- [Tutorial 2: How many latent clusters?](/nwlsm/tutorial-2-bic-clusters/): the BIC, `nwlsmselect`, clusters against the known factions of Sampson's monks, goodness of fit for binary and valued networks.
