# Links
{: .no_toc }

## Software

- [RSiena](https://github.com/stocnet/rsiena) ([CRAN](https://cran.r-project.org/package=RSiena)): stochastic actor-oriented models in R. The reference for [nwsaom](../nwsaom/).
- [statnet](https://statnet.org): the family of R packages around ergm. The reference for [nwergm](../nwergm/).
- [goldfish](https://github.com/stocnet/goldfish): dynamic network actor models and relational event models in R. The reference for [nwdynam](../nwdynam/).
- [relevent](https://cran.r-project.org/package=relevent): relational event models in R. The reference for [nwrem](../nwrem/).
- [manynet](https://github.com/stocnet/manynet) ([CRAN](https://cran.r-project.org/package=manynet)): tools for many kinds of networks in R.
- [Pajek](http://mrvar.fdv.uni-lj.si/pajek/): large-network analysis and visualization for Windows.
- [UCINET](https://sites.google.com/site/ucinetsoftware/home): social network analysis software.
- [Gephi](https://gephi.org): interactive network visualization.

## Communities

- [INSNA](https://www.insna.org), the International Network for Social Network Analysis, and its [Sunbelt conferences](https://www.insna.org/sunbelt).
- [stocnet](https://www.stocnet.org), the home of RSiena, goldfish and related software, with its [workshops](https://www.stocnet.org/workshops.html).
- The [RSiena user group](https://groups.io/g/RSiena).
- [Siena project page](https://www.stats.ox.ac.uk/~snijders/siena/): software, manuals, literature and data.
