# nwlsm tutorials
{: .no_toc }

Worked tutorials for nwlsm, with real Stata output. Install the package first (see [Install](../install/)).

- [Tutorial 1: A latent space for the karate club](/nwlsm/tutorial-1-first-lsm/): Fit a latent space model with nwlsm, check the MCMC chains, read the positions and judge the fit.
- [Tutorial 2: How many latent clusters?](/nwlsm/tutorial-2-bic-clusters/): Choose the number of clusters with the BIC (`estat bic`, `nwlsmselect`) on Sampson's monks, check them against the known factions, and check the fit for binary and valued networks.
