# The nwlsm manual

The manual is the reference for `nwlsm`. It is archived at Zenodo under the DOI of all versions, so the link always
leads to the latest manual.

**[Manual](https://doi.org/10.5281/zenodo.24398243)**

Cite it as:

> Grund, T. U. (2026). *nwlsm: Latent space models for networks in Stata. Manual.* Zenodo. [https://doi.org/10.5281/zenodo.24398243](https://doi.org/10.5281/zenodo.24398243)

together with the exact package version printed by `nwlsm version`.
