# nwsbm tutorials
{: .no_toc }

Worked tutorials for nwsbm, each with real Stata output. Install the package first (see [Install](../install/)).

- [Tutorial 1: Blocks in the karate club](/nwsbm/tutorial-1-first-sbm/): Fit stochastic block models with one to five blocks, choose the number of blocks by the ICL and read what the blocks are.
- [Tutorial 2: Covariates, the exact ICL and two-mode blocks](/nwsbm/tutorial-2-covariates-greedy/): Covariates with standard errors, the exact ICL with the greedy search, the degree-corrected two-mode model, block variances and ordered blocks.
