# The nwsbm manual

The manual is the reference for `nwsbm`. It is archived at Zenodo under the DOI of all versions, so the link always
leads to the latest manual.

**[Manual](https://doi.org/10.5281/zenodo.24398296)**

Cite it as:

> Grund, T. U. (2026). *nwsbm: Stochastic block models for networks in Stata. Manual.* Zenodo. [https://doi.org/10.5281/zenodo.24398296](https://doi.org/10.5281/zenodo.24398296)

together with the exact package version printed by `nwsbm version`.
