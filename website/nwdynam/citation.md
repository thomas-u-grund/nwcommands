# How to cite

**nwdynam.** Cite the package by its repository and report the version that produced your results, as printed by
`nwdynam version` (for example "nwdynam 1.0.1"). The package has no DOI:

> Grund, T. U. (2026). *nwdynam: a Stata package for dynamic network actor models (version 1.0.1).* GitHub. [https://github.com/thomas-u-grund/nwdynam](https://github.com/thomas-u-grund/nwdynam)

Please also cite the core package, nwcommands.

**The model and goldfish.** `nwdynam` implements the model of Stadtfeld and Block and follows goldfish, so please also cite them:

- Stadtfeld, C. and Block, P. (2017). Interactions, actors, and time: Dynamic network actor models for relational events. *Sociological Science* 4, 318-352. [doi:10.15195/v4.a14](https://doi.org/10.15195/v4.a14)
- Stadtfeld, C., Hollway, J. and Block, P. (2017). Dynamic network actor models: Investigating coordination ties through time. *Sociological Methodology* 47(1), 1-40 (if you use `submodel(choice_coordination)`).
- Hollway, J., Stadtfeld, C., Hoffman, M., Uzaheta, A. and contributors. *goldfish: Statistical Network Models for Dynamic Network Data.* R package, [CRAN](https://cran.r-project.org/package=goldfish) (compared with version 1.6.12).
