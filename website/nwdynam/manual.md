# The nwdynam manual

The manual is the reference for `nwdynam`. It covers the model (the choice, rate and coordination sub-models), installation, data preparation, every option and effect, effects through other networks, windows and weights, postestimation, stored results, worked examples with real output, the numerical comparison with goldfish, the limits and technical notes, and a translation table from goldfish.

**[Download the manual (PDF, 74 pages)](../nwdynam_manual.pdf)**

The manual describes `nwdynam` 1.11 (the current release is 1.11.0). It is archived at Zenodo under the DOI of all versions. Cite it as:

> Grund, T. U. (2026). *nwdynam: Dynamic network actor models in Stata. Manual.* Zenodo. [https://doi.org/10.5281/zenodo.24398099](https://doi.org/10.5281/zenodo.24398099)

together with the exact package version printed by `nwdynam version`.
