# nwdynam tutorials
{: .no_toc }

Worked tutorials for nwdynam, each with real Stata output. Install the package first (see [Install](../install/)).

- [Tutorial 1: A first DyNAM](/nwdynam/tutorial-1-first-dynam/): Fit a first dynamic network actor model with nwdynam to a log of phone calls: declare the events, fit the choice and the rate sub-model, and read the tables.
- [Tutorial 2: Effects and interpretation](/nwdynam/tutorial-2-effects/): Add covariates, closure effects, recency windows and weights to a DyNAM with nwdynam, and compare models by their log likelihoods.
- [Tutorial 3: Limits and diagnostics](/nwdynam/tutorial-3-limits/): What a small event log cannot tell you: a ten-event toy log gives degenerate choice-model estimates, how the standard errors shrink with more events, and the checks nwdynam makes for you.
