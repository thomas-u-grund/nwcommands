# Performance and network size
{: .no_toc }

The book *Network Analysis with Stata* gives a decision table by network size in its appendix on performance. The
table family by family, with the sizes at which each family of commands is comfortable, workable or refused and what to
do instead, is on the page **[How large a network can I analyze?](/nwcommands/size-limits/#the-table)**. That page is
kept with the software, so its figures can be newer than the printed ones.
