# nwergm tutorials
{: .no_toc }

Worked tutorials for nwergm, each with real Stata output. Install the package first (see [Install](../install/)).

- [Tutorial 1: A first ERGM](/nwergm/tutorial-1-first-ergm/): Exponential-family random graph models with the nwergm package: a first model, missing data, information criteria and goodness of fit.
- [Tutorial 2: Terms and model specification](/nwergm/tutorial-2-terms/): How to choose and read the terms of an ERGM with nwergm: structural, degree, triad and covariate terms, nodematch and nodemix, and the decay of gwesp.
- [Tutorial 3: Diagnostics and goodness of fit](/nwergm/tutorial-3-diagnostics/): Check a Monte Carlo ERGM fit with estat mcmcdiag, judge it with estat gof, and what to do when a model does not converge.
- [Tutorial 4: Missing data and comparing models](/nwergm/tutorial-4-missing-comparing/): Fit an ERGM to a network with missing dyads, compare models with AIC, BIC and likelihood-ratio tests, and compute predicted tie probabilities.
- [Tutorial 5: Constraints, two-mode networks and operators](/nwergm/tutorial-5-constraints-twomode-operators/): Restrict the sample space with constraints(), model two-mode (bipartite) networks, and use operator terms such as Symmetrize and Project in nwergm.
