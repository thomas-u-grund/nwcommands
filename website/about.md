# About

nwcommands and the model packages nwsaom, nwergm, nwdynam and nwrem are written and maintained by
**Thomas U. Grund**, RWTH Aachen University. He is the sole author of the five packages, which are free
software under the GNU General Public License, version 3.

- Code and issues: [github.com/thomas-u-grund](https://github.com/thomas-u-grund)
- Questions and bug reports: see [Get help](/help/)
- How to cite the packages: [Citing and licenses](/citing/)

The model packages follow established R packages (RSiena, ergm, goldfish, relevent) and are not affiliated
with or endorsed by their authors; see the pages of each package for what they build on.
